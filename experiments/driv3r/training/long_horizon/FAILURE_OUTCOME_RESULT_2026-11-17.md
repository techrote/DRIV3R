# FAILURE-OUTCOME-001 — empirical student suffix outcomes (negative result)

**Repo:** `techrote/DRIV3R` · **Only research PR:** [#1](https://github.com/techrote/DRIV3R/pull/1) · **branch:** `research/import-consolidated-worm-labs` · Draft/HOLD, do not merge. **Date:** 2026-11-17.

## Research question and source boundaries

Could TRAIN-only actual frozen-student continuations provide a less myopic, more durable training signal than the failed 5/12-step heuristic reward teachers? This tests a **24-decision counterfactual suffix**, with every first action drawn from the synthetic host-legal menu and all subsequent actions generated by the frozen learned student. It does not pretend to implement CyberSand's native ABI or 64-logical-move limit.

Initial remote `research/import-consolidated-worm-labs` HEAD inspected prior to editing: `89a9134ba08fb92a28ab5fec2d7b8665c46c58c5` (corpus factory worker). All six imported executable dependencies matched their exact remote Git blob SHA-1. Write scope was confined to `experiments/driv3r/training/long_horizon/`; no other worker code or external repository changed.

One bounded CPU campaign, seed **651**, 961 weights per controller. Base frozen goal/recovery model received 180 Adam updates (60 per 36→72→128 stage); each adapted controller then received 60 extra Adam updates (20 per stage) on the **same 48 student-visited TRAIN states at each stage**. These states include forced wrong turns and trap-corridor variants. No DEVELOPMENT or structural heldout state was used in training.

- `frozen`: unchanged learned base controller.
- `imitation`: baseline labels from the existing legal-action teacher.
- `survival_guard`: change an imitation label **only if** an actual frozen-student suffix is no worse on decisions completed, goal contacts and new ink, and strictly better on at least one. This is Pareto filtering, not a scalar reward.
- `outcome_aggressive`: diagnostic lexicographic preference for target contacts, decisions completed, new paint, then fewer recoveries.

**Crucial limitation:** for these TRAIN snapshots, only **1/144** sampled action-menu sets offered a first action that survived longer than the imitation action within 24 steps. Thus suffix length and state distribution are insufficient to generate substantial direct *survival* supervision. Pareto relabels mainly represent terminal contact/painting differences rather than escape from imminent termination. This is an important result, not evidence of failure prediction.

## Verdict and next discriminating experiment

**Negative:** Neither 24-step suffix preference treatment improved longer autonomous behaviour. The aggressive treatment was substantially worse, and the restrictive Pareto treatment was also inferior to matched imitation. Only one opportunity for genuinely increased suffix survival was observed: the training distribution is not informative enough to support recovery learning. The most useful next experiment is an **explicit failure-event mining pipeline** from TRAIN-only actual truncated/wrong-turn trajectories (oversampling near host-menu exhaustion, recoverability thresholds and negative/positive recovery pairs), followed by genuinely blind, fixed DEVELOPMENT evaluation and an independent second seed. Do not tune the same DEVELOPMENT fixtures until the experiment wins.
