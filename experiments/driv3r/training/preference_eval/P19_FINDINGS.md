## Explicitly non-human visual-label pilot

A separate exploratory pass visually assessed the original paintings using the assistant itself, recording **112 assistant-model-derived judgments** (46 A, 48 B, 18 TIE, zero human). These are not owner judgments, not a reward function and not a demonstrated stable aesthetic preference. The pilot assessor had already seen earlier sheets with `P18`/`P19`-prefixed IDs that indicated source cohort. Although final published gallery identifiers are source-masked, this assessor **was not fully cohort-blind**; re-rendering does not retroactively fix this bias. Keep the visual pilot labels and source reveal separate from the clean blank ballot.

Eight genuinely trained tiny *PyTorch CPU* pairwise logistic ranking probes (12 spatial/trajectory descriptors; 200 Adam updates each, 1,600 total updates) were trained separately for each niche in two source-disjoint directions: train on P18 historical, test P10 W16, and reverse. All model-derived TIE rows were excluded from binary accuracy. On the 94 non-tie test decisions across four niche ratings per original pair, **learned probe 30/94 = 31.9%; simple niche-specific transparent rule 64/94 = 68.1%; distinct-cell/coverage rule 73/94 = 77.7%**. These accuracy denominators are **correlated subjective labels**, not 94 independent experiments, and **no statistical significance or human-preference generalisation is claimed**. The learned ranker is a negative cross-source transfer result and is **NOT PROMOTED**. The coverage baseline's apparently high agreement may expose assessor preference for visibly longer traces; it is not grounds to optimize coverage as a creative objective.

These probes do not update a target pretrained SLM, use no new pretrained SLM inference, and should not be characterized as full-game preference optimisation. CPU probe checkpoint files are in the local evidence archive, **not** Git history or an immutable DRIV3R Actions artifact. No paid API/GPU was used.
