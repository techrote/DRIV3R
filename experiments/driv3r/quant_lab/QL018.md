# QL-018 — Held-out, low-bit BRANCH shadow calibration

16 November 2026. **Research-only; no promotion.** This result is a *shadow action-logit intervention*, not a newly played W0 game trajectory, and not a GGUF IQ experiment.

## Input and integrity

- Immutable original QL-017 first-pass evidence ZIP SHA-256: `ed502794143598ab26956bc5889d8eeb3dd729a947de17619767325abd0c61a5`.
- QL-017 source SHA: `cddb2e4c3fad7a03a9df6a4605dfdf48a419a369`; archive verified **336/336** inventory entries and **12,449/12,449** host-legal recorded decisions.
- Four seed groups (10611, 10623, 10647, 10651) were used for fitting; two (10667, 10679) withheld. Excluded recorded host overrides when fitting and evaluating the calibrated model choice; original world paths and scores were never changed.
- An original-parent, history-conditioned BRANCH teacher was trained on 792 legal-BRANCH observations (250 AdamW updates). On the 396 held-out parent branch-legal observations, its actual-action Brier score was **0.20395**, versus **0.21785** for the constant prevalence predictor. It is a weak *statistical personality reference*, not an action oracle or a cross-policy state match.
- Ten small correction models: for each QL-017 Q1 personality, an FP32 global bias, FP32 six-feature correction, and genuinely quantization-aware Q4/Q2/Q1 corrections (**200 AdamW optimizer updates per model; 2,250 updates total including teacher**). The legal action mask is preserved; only BRANCH logits receive additive changes. Little-endian reference bitpacks were written and decoded within numerical tolerance.

Two test seeds cannot support broad uncertainty claims.

## Interpretation

1. **A 7-byte Q4 calibration layer steers both extreme Q1 personalities toward a less pathological conditional BRANCH response** on observed held-out states. The apparent gain is against a weak learned parent-preference *surrogate*, not measured coverage, artistic quality, nor causal improvement.
2. **Lower bit depth is not monotonically better.** Q2 makes Mania into another BRANCH blackout (124 → 0), while Q1 fails to recover the original Blackout. These are preserved negative results.
3. No new pixels, trajectories, physical rendering or on-policy game results were generated by the corrections. Visual intervention maps show real historical paths with *hypothetical decision markers*, not fabricated alternate paths.
4. The measured reference median correction+argmax is about **0.018 ms per precomputed decision** for Q4 on the local CPU; this does not measure complete neural inference, end-to-end gameplay throughput, or native low-bit acceleration. Peak shared-process RSS was approximately **345.7 MiB**, not per-model RSS.
