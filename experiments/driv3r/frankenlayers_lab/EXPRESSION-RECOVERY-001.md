# DRIV3R — expressive worm recovery: matched Q8 vs Q4

**18 November 2026 | owner-directed | Draft/HOLD, research only**

## Research objective

The official Q4 GREYHOUND campaign exhibited severe STOP, constant LEFT/RIGHT and period-four loop collapse. Its earlier Q8 predecessors appeared more varied but were evaluated with different initial seeds, world families and durations. Neither difference proves quantisation was the cause. This campaign isolates model quantisation, neural layer choice and decoder stochasticity while retaining complete original 2-D trajectory evidence. The objective is **distinct nondegenerate artistic movement**, not simply surviving long enough or lowering latency.

Use the existing techrote/DRIV3R Draft/HOLD PR #1 only. Never merge/Ready/auto-merge. Do not touch CyberSand, Neurounner, native Workbench, maps or production. No paid GPU/API. The original d1-2B Q8_0 and vendor Q4_K_M are SHA256 and byte-count pinned from the same official model revision. One source-built pinned 8642541 llama.cpp serves both quantisations; the *same* System One input and legal host action interface are used.

## Phase 1: bounded matched screen

The request-only workflow .github/workflows/driv3r-expression-recovery.yml executes **only** when the dedicated expression-recovery-request.json file changes on the consolidated research branch. No routine source commit, schedule cron, PR build, or automatic optimiser launches expensive model work. Although a manual workflow_dispatch trigger is specified, GitHub normally requires the workflow to be on the default branch to expose that dispatch route; request-file pushes work while Draft/HOLD.

- Frozen executions: **stock 24**, **GREYHOUND 13**, **BRANCHWITCH 20**, **AERO4_NO2 4** and **GREY3_CUT 3** source block executions. Immutable historical masks reused unchanged.
- 3 independent initial W0 groups: **570 / Greebles**, **7703 / Pipework**, **8807 / Architecture**. All model/quant/decoder comparisons share the same initial worlds/obstacles, prompt, source, legal action menu and move budget. After a policy diverges the host state and offered legal actions may legitimately differ.
- Model variants: the original vendor **Q8** and vendor **Q4_K_M**; **no Q8→Q4 requantization**, runtime weights untouched. Pin Q8 SHA-256 073313d9...6115c6738c (1,846,240,576 bytes) and Q4 SHA-256 adca5789...43ca50b4b (1,099,629,888 bytes), verified before launching any models.
- Decoders: **greedy model argmax** versus **sampled** (temperature **1.5**, then 75% temperature-reweighted original probability plus 25% legal uniform mixture). Random draw uses deterministic common random numbers for Q8/Q4 for same seed/world/mode/step, not a fabricated movement sequence. Every recorded action must still be host legal.
- 40 decisions per case; maximum 60 cases / 2,400 model requests, actual may be fewer due to STOP. Same-runner sequential execution and CPU-only, 95-minute hard job limit. If this budget exceeds the runner, preserve partial evidence instead of replacing outputs with shorter unverifiable samples.

**Predefined negative flags:** early STOP, persistent straight-line attractor, net displacement too small, occupied-edge revisits, period-two oscillation, *period-four square loop*, or any sustained location cycle of length 2 through 16. Report turn rate, spatial footprint, new cells per decision, displacement, loop period/repetitions, branches, RETRACE and per-call latency separately. A high turn rate with no spatial progress does NOT earn an artist label.

For each case, retain exact original raw System One HTTP responses and six-way probabilities, model argmax, decoder distribution, deterministic sampling unit, actual W0 applied choice and material-independent host history. Original W0 PNG/JSON, per-case metric JSON, original SVG *painted-ink* path, and movement/retrace presentation are retained. RETRACE is pen-up; no fabricated connecting ink across a relocation. Avoid Bezier smoothing.
